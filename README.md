# Going Hostile — free web demo

A client-only demo of the Steam build of Going Hostile, a 1980s Wall Street tycoon satire. Saves stay in your browser. There is no sign-in, no real-money store, and no paid AI calls.

Play it at: https://bryansoukup.github.io/corporate-raider-demo/

Side-game preview (The Shredder): https://bryansoukup.github.io/corporate-raider-demo/preview/shredder/

This is a public preview built from the `steam` branch of `bryansoukup/bull-market-boardroom`. It is not the live iOS/web app on Lovable.
