# Corporate Raider — free web demo

A client-only demo of the Steam build. Saves stay in your browser. There is no sign-in, no real-money store, and no paid AI calls.

Play it at: https://bryansoukup.github.io/corporate-raider-demo/

This is a public preview built from the `steam` branch of `bryansoukup/bull-market-boardroom`. It is not the live iOS/web app on Lovable.
